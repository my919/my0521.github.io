3. 为项目固定 Python 版本（uv python pin）

会在当前目录生成（或更新）.python-version，记录要用的版本；之后在本目录及子目录执行 uv venv、uv run、uv sync 等时，uv 会优先按该文件选用解释器，与 pyenv 等工具习惯一致。

说明：

  • 若项目里已有 pyproject.toml 的 [project] requires-python，所 pin 的版本须满足该约束，否则 uv 会报错；需要换版本时应同时改 requires-python 与 pin，或先用 uv python pin --no-project 跳过校验（慎用）。
  • 查看当前 pin：若已有 .python-version，执行 uv python pin（不写版本号）会打印当前固定版本；若无该文件则会报错。
  • 取消 pin：uv python pin --rm。
  • 仅在当前用户全局默认：可用 uv python pin 3.14.3 --global（具体行为以官方文档为准）。

命令参考：uv python pin。

Hexo 会把 hexo new 里除标题、--path、--slug 等保留项以外的参数写进 front-matter，因此可在同一条命令里带上 categories、tags：

  • --categories：一般写一个即可（与分类页一致）。
  • --tags：需要多个标签时，重复写 --tags 标签A --tags 标签B（会生成 YAML 列表）；若只写一个字符串如 --tags "UV,Python"，会落成单个标签字符串，通常不如多次 --tags 清晰。
