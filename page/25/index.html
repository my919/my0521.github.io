第七章：Flask 入门：轻量级 Python Web 框架

概念基础

Flask 是 Python 轻量级 Web 框架（微框架）：

  1. 微内核：核心只提供路由与 WSGI 请求处理（底层为 Werkzeug），ORM、表单、认证等能力皆以扩展按需拼装，项目再大也不被框架绑架。
  2. 视图函数极简：一个函数 + @app.route 装饰器即一个接口；视图返回 dict 会被自动序列化为 JSON，非常适合 API 开发。
  3. 模块化组织：用 Blueprint（蓝图） 把路由按业务拆分（如 /api/v1），Jinja2 模板负责 HTML 渲染，大型项目也能保持结构清晰。
  4. 与 uv 无缝协作：延续前几章的项目化工作流——uv add flask 安装、uv run flask --app app run --debug 启动开发服务器，本地与 CI 环境一致。

Hexo 博客

Hexo 是基于 Node.js 的静态博客框架，用 Markdown 写作，一键生成全站并可免费部署到 GitHub Pages。下面从准备、安装、写作、预览、部署、主题与常用命令，一步步讲清楚。

概念基础

  1. 静态站点生成器（SSG）：Hexo 把 Markdown 源文件在本地渲染成纯 HTML/CSS/JS，无数据库、无后端，托管成本几乎为零。
  2. Node.js 生态：基于 Node.js 运行，hexo-cli 脚手架 + npm 插件体系，主题、部署、压缩、搜索等能力均可插件化扩展。
  3. 写作即发文：hexo new 生成带 front-matter（title/date/tags/categories）的 Markdown 文章，放入 source/_posts/（可按子目录组织）即被站点收录。
  4. 部署自由：GitHub Pages 免费上线，也可用 hexo-deployer-git 推送到 Gitee Pages、VPS 或对象存储。
  5. 主题可定制：NexT 等主题提供分类、标签、站内搜索、SEO、评论等成熟能力，站点配置集中在 _config.yml。

第六章：UV 项目开发添加 Pytest：单元测试

概念基础

pytest 是 Python 事实标准的单元测试框架：

  1. 断言极简：直接用普通 assert 语句写断言，无需记忆 xUnit 风格的 assertEquals 等方法；失败时 pytest 自动展示表达式各部分的实际值，排障高效。
  2. 自动收集：按 test_*.py / *_test.py 文件名与 test_ 前缀函数自动发现用例，无需继承基类、无需注册。
  3. 工程化配置：通过 pyproject.toml 的 [tool.pytest.ini_options] 约定测试目录（testpaths）、标记（markers）与默认参数（addopts），团队与 CI 行为一致。
  4. 生态丰富：pytest-cov 出覆盖率报告、pytest-xdist 多核并行、marker 分组筛选（-m "not slow"），并可与 uv、pre-commit（见第五章）、CI 无缝衔接。

概念基础

pre-commit 是一个 Git 提交钩子管理框架，在 git commit 前自动执行质量检查：

  1. 质量门禁前置：把 Ruff、BasedPyright、pytest 等检查放到提交时刻自动执行，不合格代码进不了仓库，避免「CI 跑一半才发现格式问题」。

第一章：Node 环境管理 nvm 实践

发表于 2026-04-30 更新于 2026-09-01 分类于 Node 本文字数： 1.4k 阅读时长 ≈ 5 分钟

第一章：Node 环境管理 nvm 实践

概念基础

  1. 为什么需要版本管理：Node 大版本迭代快，LTS 与 Current 并行发布，不同项目常依赖不同 Node 版本——全局只装一个版本很快就捉襟见肘。
  2. nvm 的解决思路：nvm（Node Version Manager）从源码或官方预编译包拉取 Node，把各版本隔离安装在用户目录 $HOME/.nvm 下，通过 nvm use 切换当前终端使用的 node / npm，各版本互不干扰。
  3. 与全局安装的区别：不把某个 Node 强行装进系统目录，无需 root 权限；切换版本只影响当前 Shell（及子进程），其他终端不受牵连。
  4. 按项目锁定版本：项目根目录放一个 .nvmrc 写明版本号，进入目录执行 nvm use 即可对齐环境，避免「在我机器上能跑」的版本漂移。

第一章：Python 的 UV 工具：极速 Python 环境与包管理

概念基础

UV 是 Astral（Ruff 的开发团队）用 Rust 编写的 Python 包与项目管理器：

  1. 快是核心卖点：依赖解析与安装比传统 pip / pip-tools 快 10~100 倍，得益于 Rust 实现、并行下载与全局缓存。
  2. 一体化工具链：一个 uv 命令覆盖 Python 解释器管理（uv python）、虚拟环境（uv venv）、包安装（uv pip / uv add）、项目初始化与同步（uv init / uv sync）与命令运行（uv run），替代过去 pyenv + venv + pip + pip-tools 的多件套拼装。
  3. 兼容 pip 生态：uv pip 提供 pip 兼容接口，老命令、老脚本可平滑迁移；同时拥抱 pyproject.toml 标准与 uv.lock 锁文件，保证环境可复现。
  4. 适用场景：从单脚本、单项目到 monorepo 工作区都能胜任；本章先掌握安装、解释器、虚拟环境、依赖管理四大基础能力。
