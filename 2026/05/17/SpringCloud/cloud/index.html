概述

本页为 cloud 微服务工程的 Hexo 文档索引与总览，各专题见下方链接。

基于 Spring Boot 4.0.0、Spring Cloud 2025.1.0、Spring Cloud Alibaba 2025.1.0.0 的示例工程。下列单篇为 Hexo 博文（含 Front Matter），复制到 _posts/ 即可发布。

仓库：https://gitee.com/my919/cloud

架构总览

业务上，下单扣库存走 cloud-order → Feign → cloud-stock，由 Seata AT 保证跨服务一致性；配置与注册走 Nacos；流控熔断走 Sentinel（可选 Dashboard）。

服务与端口

服务 注册名 默认端口 职责
cloud-gateway cloud-gateway 9000 统一入口、路由、网关 Sentinel
cloud-user cloud-user 8001 用户域示例、Swagger
cloud-app cloud-app 8002 BFF、Feign 调 user、Swagger
cloud-order cloud-order 8003 订单、Seata TM、POST /order/place
cloud-stock cloud-stock 8004 商品库存、Seata RM
cloud-common — — 公共配置与 Result，非独立进程

推荐启动顺序

  1. 基础设施：MySQL（执行 sql/init.sql、sql/seata-undo_log.sql、sql/test-data-goods.sql）→ Nacos → Seata TC →（可选）Sentinel Dashboard
  2. 业务服务：cloud-stock → cloud-order → cloud-user → cloud-app
  3. cloud-gateway（确保下游已在 Nacos 注册）
  4. 验证：GET http://127.0.0.1:9000/stock/goods/1，POST /order/place（见专题文档）

构建与运行

代码风格：mvn spotless:apply；CI：mvn verify。
