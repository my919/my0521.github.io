订单下单与库存扣减

发表于 2026-05-17 更新于 2026-05-24 分类于 SpringCloud 本文字数： 619 阅读时长 ≈ 2 分钟

概述

核心链路：下单 POST /order/place（cloud-order）→ OpenFeign → 扣库存 POST /stock/goods/deduct（cloud-stock）。成功时写入 t_order 并减少 goods.stock；失败时由 Seata 全局事务 回滚（默认开启）。测试数据见 sql/test-data-goods.sql。

流程



sequenceDiagram
  participant C as Client
  participant G as Gateway
  participant O as cloud-order
  participant S as cloud-stock
  participant DBo as DB order
  participant DBs as DB stock

  C->>G: POST /order/place
  G->>O: 转发
  O->>O: @GlobalTransactional
  O->>DBo: INSERT t_order
  O->>S: Feign deductGoods
  S->>DBs: UPDATE goods SET stock
  alt stock OK
    O-->>C: code 0
  else stock不足
    S-->>O: 业务异常
    O->>O: 全局 rollback
    O-->>C: code 1
  end

API

统一响应：Result，code==0 成功，code==1 业务失败。

验证清单

  1. 成功：place 返回 code:0；GET /stock/goods/1 库存减少 2；t_order 新增记录。
  2. 回滚：使用 goodsId=3、qty=10；返回 code:1；goods 3 库存仍为 2；order 日志含 Rollbacked。
  3. Seata：order 日志 Begin new global transaction；TC 30014 可达。
  4. 单元测试：mvn -pl cloud-order test → OrderServiceImplTest、OrderPlaceIntegrationTest。

常见问题

Q：PowerShell 里 curl 报 400 或 JSON 错误？
A：使用 curl.exe 或 -d "@文件"；勿用 curl 别名；复杂 JSON 用 Invoke-RestMethod + 文件读入。

Q：GET /order/place 报错？
A：place 仅支持 POST。

Q：回滚后 order 表仍有脏数据？
A：查 Seata 是否启用、TC 是否连通、undo_log 是否已建；看 order 日志是否 commit 而非 rollback。

Q：Feign 超时导致不确定状态？
A：调大 spring.cloud.openfeign 超时或重试策略；生产建议幂等与查询补偿。
