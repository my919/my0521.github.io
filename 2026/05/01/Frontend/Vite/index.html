Vite

发表于 2026-05-01 更新于 2026-05-31 分类于 Frontend 本文字数： 430 阅读时长 ≈ 1 分钟

Vite 是新一代前端构建工具：开发阶段利用浏览器原生 ESM 与 esbuild 预构建依赖，实现秒级冷启动；生产构建使用 Rollup 打包。下面从「开发与生产模式 → 创建项目 → 配置要点 → 插件与代理 → 与 Vue/React 的关系」顺序写清楚。

Dev vs Build



flowchart LR
  subgraph dev [开发 vite dev]
    SRC[源码 ESM] --> ESB[esbuild 预构建 deps]
    ESB --> HMR[浏览器 HMR]
  end
  subgraph prod [生产 vite build]
    SRC2[源码] --> ROL[Rollup 打包]
    ROL --> DIST[dist 静态资源]
  end

一、为何快

阶段 机制
开发 按需编译单文件，不打包整图；依赖用 esbuild 预打包
HMR 模块热替换，保留应用状态（依模块类型）
生产 Rollup Tree-shaking、代码分割、资源哈希

对比 Webpack dev：大型项目冷启动与 HMR 通常明显更快。

二、创建与脚本

常用模板：vanilla-ts、vue-ts、react-ts、vue。

三、vite.config.ts 要点

  • base：部署子路径时设为 '/blog/' 等。
  • env：.env.development 中 VITE_* 变量通过 import.meta.env 暴露。

四、插件生态

  • @vitejs/plugin-vue / plugin-react
  • vite-plugin-vue-devtools
  • Legacy：@vitejs/plugin-legacy 为旧浏览器注入 polyfill

SSR：vite-plugin-ssr 或框架内置方案（Nuxt 3 等基于 Vite）。

五、与 Vue 3 及部署

  • VUE3 官方推荐 **Vite** 作为默认脚手架。
  • 生产 dist 为静态文件，由 Nginx 或 CDN 托管；try_files 支持 SPA history 模式。

官方文档：https://vite.dev/
