VUE3

发表于 2026-05-01 更新于 2026-05-31 分类于 Frontend 本文字数： 406 阅读时长 ≈ 1 分钟

Vue 3 是渐进式前端框架：采用 Composition API、Proxy 响应式、更小的运行时与更好的 TypeScript 支持。下面从「核心概念 → Composition API → 组件与路由 → 状态管理 → 与 Vite 工程的关系」顺序写清楚。

组件与数据流



flowchart TB
  Props[props 父传子] --> Comp[Vue 组件 SFC]
  Comp --> Emit[emit 子传父]
  Comp --> Store[Pinia 全局状态]
  Store --> Comp

一、核心概念

  • 单文件组件（SFC）：.vue 含 <template>、<script>、<style>。
  • 响应式：ref / reactive 包装数据，模板自动追踪依赖并更新 DOM。
  • 虚拟 DOM + 编译优化：静态提升、补丁标志减少运行时开销。

与 Vue 2：移除 Vue.set、$on 等 API；全局 API 改为 createApp。

二、Composition API 示例

  • script setup：编译期糖，少写 export default。
  • 组合式函数（Composables）：useXxx() 抽离可复用逻辑。

三、组件通信

方式 说明
Props / Emits 父 → 子、子 → 父事件
Provide / Inject 跨层级依赖注入
v-model 双向绑定（modelValue + update:modelValue）
Slots 默认插槽、具名插槽、作用域插槽

四、路由与状态

  • Vue Router 4：createRouter、嵌套路由、导航守卫、懒加载 () => import('./Page.vue')。
  • Pinia：官方推荐状态库，替代 Vuex，模块即 defineStore。

五、工程化

推荐使用 Vite 创建项目：

  • 类型检查：vue-tsc --noEmit
  • UI 库：Element Plus、Naive UI、Ant Design Vue 等
  • 构建产物：静态资源可部署到 Nginx

官方文档：https://vuejs.org/
