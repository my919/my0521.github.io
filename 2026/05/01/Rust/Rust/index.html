Rust

概念基础：Rust 是什么/为什么

  1. 系统级编程语言：Rust 定位与 C/C++ 相同，面向操作系统、数据库、网络服务等对性能与控制力要求极高的场景，编译为原生机器码，无虚拟机、无 GC。
  2. 内存安全是核心卖点：通过所有权（ownership）与借用检查在编译期阻止悬垂引用、use-after-free 与数据竞争，不依赖运行时垃圾回收兜底。
  3. 零成本抽象：Option/Result、迭代器、泛型与 trait 等高层抽象编译后不引入额外运行时开销，安全与性能可以兼得。
  4. 现代化工程体验：官方工具 Cargo 集构建、测试、文档与依赖管理于一体，配合 crates.io 社区仓库，上手与协作成本远低于传统 C/C++。
  5. 适用场景广泛：CLI 工具、Web 后端、Wasm、嵌入式，也可通过 FFI 与 C/C++ 混编，为既有系统替换性能或安全热点。

一、所有权与借用

1. 三条规则

  1. 每个值有且仅有一个所有者。
  2. 所有者离开作用域，值被 drop。
  3. 同一时间只能有一个可变引用，或任意多个不可变引用（不能同时存在可变与不可变引用）。

六、生命周期

生命周期标注不改变引用实际存活时长，只是向编译器声明「这些引用的存活期相同」。编译器据此判断引用是否比被引用者活得长（悬垂引用会被拒绝）。

省略规则：函数只有一个输入生命周期参数时，输出生命周期默认与之一致；方法中 &self/&mut self 的输出默认与 self 同寿命。多数场景无需手写标注。

本章小结

要点 结论
所有权 每个值一个所有者，赋值即移动（Copy 类型除外），出作用域自动 drop
借用规则 同一时刻要么一个 &mut，要么多个 &，编译期拒绝数据竞争
数据类型 标量（整/浮/bool/char）+ 复合（元组/数组）；String 堆可变、&str 切片引用
控制流 if 是表达式；loop/while/for；match 穷尽模式匹配
struct/enum struct+impl 组织数据与方法；enum 建模多态，Option<T> 取代 null
trait/泛型 trait 定能力、泛型做抽象；impl Trait 静态分发、dyn Trait 动态分发
生命周期 标注引用同寿关系，编译期防悬垂；'static 存活整个程序期
集合/迭代器 Vec/HashMap 常用；迭代器惰性、零成本，map/filter/collect 链式
模块/Cargo mod/use/pub 组织可见性；Cargo 统一构建/测试/依赖
错误处理 Result+? 传播可恢复错误，panic! 用于不可恢复；库返回 Result、应用顶层 unwrap
标准库 fs/io、path、env/process、time、fmt、cmp/ops 覆盖日常九成需求
并发 Send/Sync 标记线程安全；Arc/Mutex 共享可变、mpsc 消息传递、async/await（Tokio）支撑高并发 IO
生态 Cargo + crates.io 一站式工程化，CLI/Web/Wasm/嵌入式均有成熟方案
