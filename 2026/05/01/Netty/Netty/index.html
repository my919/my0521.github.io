Netty

发表于 2026-05-01 更新于 2026-05-31 分类于 Netty 本文字数： 452 阅读时长 ≈ 2 分钟

Netty 是 Java 异步事件驱动网络框架，封装 NIO / Epoll，提供 Channel、EventLoop、Pipeline 等抽象，用于高并发 TCP/UDP、HTTP、WebSocket 服务端与客户端。下面从「定位 → 核心组件 → Pipeline 与 Handler → 启动流程 → 与多路复用专题的关系」顺序写清楚。

一、定位

  • Reactor 模型：少量 EventLoop 线程通过 Selector 监视大量 Channel。
  • 零拷贝与缓冲：ByteBuf 池化、CompositeByteBuf 等减少拷贝（具体依版本与平台）。
  • 协议栈：内置或社区 Codec（HTTP、Redis、MQTT 等），也可自定义帧解码。

典型用户：Dubbo、gRPC-Java（部分）、Elasticsearch、游戏网关、物联网接入。

二、核心组件

组件 说明
EventLoopGroup 线程池，每个 EventLoop 绑定 Selector
Channel 网络连接抽象（NioSocketChannel 等）
ChannelPipeline Handler 双向链表，入站/出站事件传播
ChannelHandler 编解码、业务逻辑、空闲检测等
Bootstrap / ServerBootstrap 客户端/服务端启动辅助类

三、Pipeline 示例（概念）

  • 入站：socket 读 → 解码 → 业务 Handler。
  • 出站：业务写 → 编码 → socket 写。
  • 共享 Handler：注意 @Sharable 与线程安全。
