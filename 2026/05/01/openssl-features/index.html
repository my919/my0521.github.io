发表于 2026-05-01 更新于 2026-05-31 分类于 OpenSSL 本文字数： 1.1k 阅读时长 ≈ 4 分钟

OpenSSL 有两层身份：

  1. 命令行工具（你刚才用的：生成证书、密钥）
  2. 底层密码库（几乎所有软件的加密都靠它：Nginx、Python、Java、curl、安卓、iOS 等）

90% 的互联网加密通信，底层都在用 OpenSSL。

命令行生成证书、CSR、格式转换等逐步操作见 OpenSSL 常用操作完整指南。

二、OpenSSL 到底能做什么？

1. 证书体系

  • 生成私钥、公钥
  • 生成自签名证书（本地/内网开发）
  • 生成 CSR（向 CA 申请正式 HTTPS 证书）
  • 查看证书信息
  • 证书格式转换（PEM ↔ PFX ↔ DER）

7. 签名 & 验签

确保文件不被篡改、来源可靠（软件发布、固件验证必备）：

  • 私钥签名
  • 公钥验签

8. 支持所有主流加密算法

  • RSA、ECC（非对称加密）
  • AES、ChaCha20（对称加密）
  • SHA256、SHA3、MD5（哈希）
  • TLS 1.3 / QUIC 等最新协议

三、哪些软件在底层使用 OpenSSL？

  • Nginx / Apache（HTTPS 加密）
  • curl / wget
  • Python / PHP / Node.js
  • Android / iOS 系统加密
  • Docker / Kubernetes
  • Wi-Fi 加密、VPN、SSH
  • 你的浏览器底层密码库

一句话：互联网加密的基石。

四、极简总结（记这 4 点就够）

  1. 是工具：生成证书、加密文件、测试 HTTPS
  2. 是库：几乎所有软件加密都靠它
  3. 全覆盖：HTTPS、TLS、QUIC、VPN、SSH 全支持

iOS
