OpenCV（Open Source Computer Vision Library）是开源计算机视觉库：图像读写、几何变换、特征检测、目标跟踪、相机标定等，提供 C++ 核心与 Python 绑定。下面从「安装与基本 I/O → 图像处理 → 特征与匹配 → 与 DL 的结合 → 与 FFmpeg 的关系」顺序写清楚。

二、常用图像处理

  • 色彩空间：BGR、HSV、Lab。
  • 形态学：erode / dilate / morphologyEx。
  • 阈值：threshold、adaptiveThreshold。

三、特征与几何

API 用途
ORB/SIFT/SURF 关键点与描述子（版本与专利注意）
findHomography 透视变换、文档扫描
matchTemplate 模板匹配
CascadeClassifier 经典 Haar 人脸检测（演示级）

生产级检测/分割多改用 PyTorch + YOLO、Mask R-CNN 等 DL 模型；OpenCV 负责前后处理（resize、NMS 辅助、绘制框）。
