OpenCV

概念基础：OpenCV 是什么/为什么

  1. 计算机视觉基础库：OpenCV 提供图像读写、滤波、几何变换、特征提取、视频处理等数百个现成算法，是 CV 领域事实上的标准库。
  2. 图像即数组：图像在 Python 中以 NumPy 数组表示，注意 OpenCV 默认 BGR 通道顺序而非 RGB，所有处理本质上都是数组运算。
  3. C++ 内核、多语言绑定：核心由 C++ 实现保证性能，Python 通过 cv2 绑定调用，兼顾开发效率与运行速度。
  4. 传统 CV 与深度学习的桥梁：自带 cv2.dnn 可加载 ONNX 等模型推理，更多时候负责深度模型前后的预处理与后处理。
  5. 跨平台易上手：桌面、移动、嵌入式均可运行，pip install opencv-python 即可开始。
