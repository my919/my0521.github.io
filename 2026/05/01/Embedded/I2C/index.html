I2C

发表于 2026-05-01 更新于 2026-05-31 分类于 Embedded 本文字数： 354 阅读时长 ≈ 1 分钟

I²C（Inter-Integrated Circuit）是两线同步串行总线：SDA（数据）、SCL（时钟），多主多从，用 7 位/10 位地址寻址。下面从「时序 → 寻址与读写 → 上拉与速率 → 典型外设 → 与 SPI/UART 对照」顺序写清楚。

一、信号与起始/停止

  • 空闲：SDA、SCL 均为高（靠上拉电阻）。
  • START：SCL 高时 SDA 下降沿。
  • STOP：SCL 高时 SDA 上升沿。
  • 数据位：SCL 低时 SDA 变化，SCL 高时采样。

二、7 位地址帧（写）

读操作：写寄存器指针 → 重复 START → 读地址 + 读数据 + NACK + STOP。

三、速率模式

模式 速率
Standard 100 kHz
Fast 400 kHz
Fast Mode Plus 1 MHz
High Speed 3.4 MHz（较少用）

上拉电阻：常见 2.2k~10k（3.3V、总线电容与速率相关）；长电缆或多设备需降低电容、可能用 I2C 缓冲器/扩展器。

四、典型设备

  • EEPROM（24Cxx）、RTC（DS3231）、IMU、OLED 小屏、PMIC、GPIO 扩展（PCF8574）。
  • 同一地址冲突：部分芯片有 ADDR 引脚改地址；否则需不同总线（I2C mux）。

五、与 SPI、UART

总线 线数 速度 特点
I2C 2 + GND 中 多从、地址、开漏
SPI 4+ 高 全双工、无标准地址
UART 2 + GND 中 点对点、异步

CAN 用于车载/工业现场总线，抗干扰与仲裁不同于 I2C。
