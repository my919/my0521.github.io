LoRaWAN

发表于 2026-05-01 更新于 2026-05-31 分类于 Embedded 本文字数： 352 阅读时长 ≈ 1 分钟

LoRaWAN 是基于 LoRa 物理层的远距离广域网协议：星型拓扑，终端 ↔ 网关 ↔ 网络服务器，低功耗、公里级距离、kbps 级速率。下面从「频段与速率 → Class A/B/C → 入网与密钥 → 与 CoAP/MQTT → 应用场景」顺序写清楚。

星型拓扑



flowchart TB
  Dev1[终端节点] --> GW[LoRa 网关]
  Dev2[终端节点] --> GW
  GW --> NS[Network Server]
  NS --> App[应用服务器]

一、架构

  • Gateway：只做射频转发，不解密应用 payload（取决于模式）。
  • ADR（Adaptive Data Rate）：网络侧调节 SF/功率平衡距离与容量。

二、区域参数

区域 典型频段
EU868 863–870 MHz
US915 902–928 MHz
CN470 470–510 MHz

需遵守当地无线电法规；模块需合规认证。

三、设备 Class

Class 下行窗口 功耗
A 仅上行后两个短窗口 最低，传感器常用
B 附加信标窗口 中
C 几乎常开接收 高，供电设备

四、安全

  • Join：OTAA（Over-The-Air Activation，推荐）或 ABP（预置密钥）。
  • AES-128：NwkSKey、AppSKey 分层加密与完整性。
  • 应用层仍可封装 CoAP 或自定义二进制。

五、与其它物联网协议

  • 长距离、低带宽、电池 → LoRaWAN。
  • 有 Wi-Fi/以太网、高吞吐 → MQTT、HTTP。
  • 局域 mesh → Zigbee、Bluetooth Mesh。

开源栈：LoRaMac-node、Semtech LoRaWAN Stack；云平台：TTN、ChirpStack 等。
