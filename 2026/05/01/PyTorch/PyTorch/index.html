PyTorch

概念基础：PyTorch 是什么/为什么

  1. 主流深度学习框架：PyTorch 以动态计算图著称，写 Python 即写模型，科研与工业界均为主流选择，是上手深度学习的首选框架。
  2. Tensor 是基本数据结构：torch.Tensor 是可在 CPU/CUDA 上运算的多维数组，接口与 NumPy 相似，但支持 GPU 加速与自动求导。
  3. autograd 自动微分：开启 requires_grad 的张量参与运算时自动记录计算图，调用 backward() 即得梯度，无需手推公式。
  4. nn.Module + 优化器构成训练范式：模型继承 nn.Module 定义 forward，配合损失函数与 optimizer.step() 循环迭代即可完成训练。
  5. 生态覆盖全链路：torchvision/torchaudio 领域库、Hugging Face 预训练模型、TorchScript/ONNX 导出部署、DDP 分布式训练。

训练循环



flowchart TD
  DL[DataLoader batch] --> F[model forward]
  F --> Loss[loss.backward]
  Loss --> Opt[optimizer.step]
  Opt --> DL

一、Tensor 与 autograd

  • torch.Tensor：CPU/CUDA 上的多维数组。
  • requires_grad：参与自动微分；backward() 累积梯度。
  • 推理：with torch.no_grad(): 或 model.eval() 关闭 Dropout 等。

二、模型与训练循环

nn.Module：子类化 forward 组织复杂网络（CNN、Transformer 等）。

三、DataLoader

num_workers 多进程加载；pin_memory=True 加速 CPU→GPU 拷贝。

四、GPU 与混合精度

torch.compile（2.x）可进一步融合内核优化推理/训练。

五、生态与延伸

  • torchvision / torchaudio / torchtext：领域数据集与模型。
  • Hugging Face：Transformers 加载 第三章：LLM 大语言模型基础。
  • 导出：TorchScript、ONNX 用于 C++/移动端推理。
  • 分布式：DDP（DistributedDataParallel）多卡训练。

理论背景见 第二章：DL 深度学习基础；Python 项目管理见 第一章：Python 的 UV 工具：极速 Python 环境与包管理。

官方：https://pytorch.org/docs/
