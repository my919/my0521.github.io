SFTP 详解：SSH 子系统、协议栈与 sftp 示例

发表于 2026-05-01 更新于 2026-05-04 分类于 Protocol 本文字数： 377 阅读时长 ≈ 1 分钟

SFTP（SSH File Transfer Protocol）在 SSH 加密通道上提供文件列表、上传、下载、权限修改等能力；与 FTP 的双连接明文模型无关，也不等于 FTPS（FTP+TLS）。下面从「作用与协议栈 → 与 SCP 区别 → 交互与批处理示例 → ssh 管道技巧」顺序写清楚。

一、作用与协议栈（原理）

SFTP 是 SSH 协议族中的子系统，与 shell 会话可并存于同一 SSH 连接实现上（由服务器策略决定）。

二、与 SCP、rsync over SSH 的取舍

工具 说明
SFTP 交互浏览目录、断点续传能力依客户端而定
scp 单次拷贝简单文件
rsync -e ssh 增量同步目录，底层仍是 SSH 隧道，协议不等同于 SFTP
