SSH 详解：加密远程登录、密钥与端口转发示例

发表于 2026-05-01 更新于 2026-05-31 分类于 Protocol 本文字数： 441 阅读时长 ≈ 1 分钟

SSH（Secure Shell）在不安全网络上提供加密远程 shell、文件传输（SFTP）与隧道。常见实现 OpenSSH 默认 TCP/22。下面从「协议目标 → 主机密钥与用户认证原理 → ssh_config / sshd_config → 本地端口转发示例 → 安全运维要点」顺序写清楚。

一、协议目标（作用）

  • 机密性与完整性：防窃听与篡改。
  • 身份认证：至少认证服务器；可双向证书或密钥。
  • 隧道能力：为其他 TCP 应用提供加密通道。
