Maven 构建工具

发表于 2026-05-01 分类于 Java 本文字数： 1k 阅读时长 ≈ 3 分钟

Apache Maven 是 Java 项目常用的依赖管理与构建工具，用 pom.xml 描述坐标、依赖与生命周期，一条命令完成编译、测试、打包。下面从官网、前置条件、Windows / Rocky Linux 安装、环境变量到国内镜像加速，按步骤写清楚。

一、官网与发行包

  • 项目官网：https://maven.apache.org/
  • 下载页（Binary zip / tar.gz）：https://maven.apache.org/download.cgi
    选择当前稳定版的 apache-maven-*-bin.zip（Windows）或 apache-maven-*-bin.tar.gz（Linux）。

安装前需已安装 JDK 8+（建议 JDK 17 或 21 LTS），终端可执行 java -version 验证。

七、小结

项 说明
官网 https://maven.apache.org/
Windows 默认解压到 **C:\app\**，配置 MAVEN_HOME 与 Path 中的 %MAVEN_HOME%\bin
Rocky Linux dnf install maven（路径随包）或官方包解压到 /usr/local/ 并设 MAVEN_HOME=/usr/local/maven
加速 ~/.m2/settings.xml 配置阿里云等镜像
验证 mvn -v

完成以上步骤后，本机即可稳定使用 Maven 构建 Java 项目。
