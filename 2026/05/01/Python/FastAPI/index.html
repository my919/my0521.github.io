FastAPI

发表于 2026-05-01 分类于 Python 本文字数： 435 阅读时长 ≈ 1 分钟

FastAPI 是基于类型标注的 Python Web 框架，适合写 API，常与 Uvicorn（ASGI 服务器）一起用。本文假定本机已安装 uv，且已有可用的 Python 解释器（本站约定 3.14.3；uv 与解释器准备见同栏《Python的UV工具》《UV从0到1创建项目》）。下文只写在该前提下用 uv 建项、安装依赖、编写最小应用并用 Uvicorn 本地运行。

一、前提

  • uv 可用：uv --version 正常。
  • Python 已就绪（推荐 3.14.3）；新项目里可 uv python pin 3.14.3 固定版本。
  • 若环境未就绪，请先阅读上述两篇 UV 文档。

二、用 uv 初始化项目并安装依赖

  • fastapi：框架本体。
  • uvicorn[standard]：本地/生产常用的 ASGI 服务进程；[standard] 包含 httptools、uvloop 等加速依赖（在 Windows 上部分组件会自动降级，属正常行为）。

五、小结

场景 命令
安装依赖 uv add fastapi "uvicorn[standard]"
同步环境 uv sync
开发运行 uv run uvicorn main:app --reload
指定 host/port uv run uvicorn main:app --host 0.0.0.0 --port 8080

依赖注入、后台任务、WebSocket、与 SQLModel / SQLAlchemy 集成等见 FastAPI 文档。
