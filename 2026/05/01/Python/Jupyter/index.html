Jupyter 入门：经典 Notebook、安装与内核

发表于 2026-05-01 更新于 2026-05-04 分类于 Python 本文字数： 779 阅读时长 ≈ 3 分钟

Jupyter 指以浏览器为界面、单元格为单位交互运行代码的笔记本生态；日常所说的「Notebook」多指经典 jupyter notebook 界面（文档扩展名 .ipynb）。下面从「官网与组成 → 环境准备 → 安装与启动 → 内核与 .ipynb 要点 → 与 JupyterLab 的关系」顺序写清楚；命令在 Linux / macOS 终端或 Windows PowerShell 中执行（已安装 Python 3.10+ 为前提）。多用户与统一入口见站内 JupyterHub 入门；下一代单用户界面见 JupyterLab 入门。

一、官网与组成

  • Jupyter 项目主页：https://jupyter.org/
  • Notebook 文档（经典界面）：https://jupyter-notebook.readthedocs.io/
  • .ipynb 格式说明：以当前 nbformat 文档为准（Notebook 文件为 JSON，含代码单元、输出与元数据）。

Jupyter 与具体「前端」解耦：Notebook 与 JupyterLab 都能打开同一 .ipynb；底层常由 jupyter_server 提供 HTTP 与 WebSocket 服务。团队若只需单用户本机或单容器写分析，Notebook 或 JupyterLab 二选一即可。

二、环境准备

  1. 安装 Python 3.10+，终端可执行 python --version（或 python3，下文统一写 python，请按本机替换）。
  2. 建议使用虚拟环境（venv、conda 或站内 uv 工具），避免把 Jupyter 装进全局 site-packages 难以清理。

--ServerApp.ip=0.0.0.0 会监听所有网卡，仅在可信内网或已配反向代理与认证时使用；公网暴露须配合 HTTPS、强鉴权 或专用网关（多用户场景更适合 JupyterHub）。

四、内核与 .ipynb 要点

1. 内核（Kernel）

内核是执行代码的进程；Python 环境装了 ipykernel 并注册后，Notebook 右上角可选该内核。

2. 单元格类型

常见为 Code（运行代码）与 Markdown（写说明）；Shift+Enter 执行当前单元并跳到下一单元（具体快捷键以界面 Help 为准）。

3. 保存与版本

.ipynb 含输出时体积会变大；纳入 Git 前团队可约定是否清空输出再提交，或使用 nbstripout 等工具（按需查阅文档）。

五、与 JupyterLab 的取舍

需求 建议
习惯经典菜单、轻量界面 继续用 jupyter notebook
多文件标签、内置终端、扩展生态 使用 JupyterLab（jupyter lab）
多用户、登录与配额 使用 JupyterHub

二者可同一虚拟环境内并存：同时安装 notebook 与 jupyterlab 并不冲突。

六、小结

项 说明
定位 浏览器中的交互式笔记本；经典命令 jupyter notebook
安装 python -m pip install notebook；常配合 ipykernel
启动 注意 token 与 127.0.0.1 监听范围
延伸 JupyterLab · JupyterHub

更完整的配置项（密码、证书、扩展目录）以 jupyter_server / Notebook 当前大版本文档为准。
