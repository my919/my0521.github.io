网页自动化（Python + Selenium）

发表于 2026-05-01 分类于 Python 本文字数： 935 阅读时长 ≈ 3 分钟

Selenium 用代码驱动真实浏览器做点击、填表、截图与回归验证，是 Python 里最常见的网页自动化方案之一。下面按「准备环境 → 安装库 → 浏览器与驱动 → 第一个脚本 → 无头与常用选项 → 等待与定位要点」顺序写清楚；版本以 Selenium 4.x 与 Python 3 为准。

一、环境准备（必须）

  1. Python 3.14.3（本站 Python 栏统一版本；Selenium 亦兼容 3.10+）：终端能执行 python3 -V 与 pip --version。
  2. Google Chrome 或 Microsoft Edge（Chromium 系）或 Mozilla Firefox 之一，用于本地实际打开页面。
  3. 编辑器：VS Code、PyCharm 等任选其一。

三、浏览器与驱动

1. Selenium Manager（推荐，Selenium 4.6+）

Selenium 4.6 起内置 Selenium Manager，在常见环境下会自动解析本机已安装的 Chrome / Edge / Firefox 并匹配驱动，多数情况无需再手动下载 chromedriver。若启动报错，先升级 Selenium 与浏览器到较新版本。

2. 仍失败时的排查顺序

  1. 浏览器是否已安装且能手动打开。
  2. pip install -U selenium 是否已升级到当前 4.x 最新补丁版。
  3. Linux 无图形界面时是否已使用下文「无头」方式，或已配置 Xvfb 等显示环境。
  4. 企业环境若禁止自动拉驱动，再按官方文档改为显式指定驱动路径或使用自带浏览器的容器镜像。

官方文档：https://www.selenium.dev/documentation/

六、等待与元素定位（避免「找不到元素」）

页面加载有异步请求时，固定 sleep 不稳，建议：

  1. 显式等待：WebDriverWait + expected_conditions，在超时时间内轮询条件。
  2. 定位方式：优先 id / data-testid / 稳定 name；少用绝对 XPath。
  3. 点击被挡：先滚动到视区 element.location_once_scrolled_into_view，或等待浮层消失。

七、与 pytest 搭配（可选）

  1. 安装：pip install pytest。
  2. 测试文件命名 test_*.py，用 assert 断言页面结果。
  3. 每个用例结束务必 driver.quit()，或用 pytest fixture 统一创建与销毁浏览器，避免僵尸进程。

八、小结

步骤 内容
环境 Python 3 + 浏览器 + pip
安装 pip install selenium（建议虚拟环境）
驱动 Selenium 4.6+ 优先依赖 Selenium Manager
入门 webdriver.Chrome() + get / title / quit
稳定 显式等待 + 稳定定位 + 无头参数按需配置

更复杂的录制回放、分布式 Grid、与 CI 集成等，可在掌握上述流程后查阅 Selenium 官方文档按场景扩展。
