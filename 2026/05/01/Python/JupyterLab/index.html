JupyterLab 入门：安装、工作区与扩展

发表于 2026-05-01 更新于 2026-05-04 分类于 Python 本文字数： 684 阅读时长 ≈ 2 分钟

JupyterLab 是 Jupyter 项目的下一代单用户 Web 界面：多文档标签、文件浏览器、终端与笔记本同屏工作流，底层同样基于 jupyter_server。下面从「官网与定位 → 安装 → 启动与安全习惯 → 工作区与常用面板 → 扩展 → 与 Notebook / Hub 的关系」顺序写清楚；命令在 Linux / macOS 或 Windows 下 Python 3.10+ 虚拟环境中执行。经典界面见 Jupyter 入门；多用户入口见 JupyterHub 入门。

一、官网与定位

  • JupyterLab 文档：https://jupyterlab.readthedocs.io/
  • Jupyter 总览：https://jupyter.org/

JupyterLab 与 jupyter notebook 共享 .ipynb 与内核模型；迁移时一般无需改文件格式，主要是换启动命令与操作习惯。

三、启动与安全习惯

1. 默认启动

终端打印的 URL 含 token=；--no-browser 适合在远程服务器上只复制链接到本地浏览器打开。

2. 端口与监听地址

  • 127.0.0.1：仅本机访问，适合本地开发。
  • 0.0.0.0：监听所有网卡，便于 SSH 端口转发 或容器内访问，但须配合防火墙与认证，勿在公网裸奔。

3. 配置密码与 HTTPS（生产必读）

长期使用可配置 ServerApp.password（哈希）与证书，详见 Jupyter Server 文档中的 Security 章节；团队统一入口请评估 JupyterHub。

四、工作区与常用能力

能力 说明
文件浏览器 左侧打开工作目录下 .ipynb、文本与图片
Notebook 与经典界面相同的单元格执行模型
Console 与内核绑定的「控制台」，适合试片段代码
Terminal 内置终端（依赖系统 shell），在远程环境非常方便
Workspace 布局可保存；关闭前注意 File → Save Workspace（以当前版本菜单为准）

六、与 Jupyter / JupyterHub 的关系

  • 经典 Notebook：见 Jupyter 入门，命令为 jupyter notebook。
  • JupyterHub：在 Hub 后为用户各自拉起 单用户服务器，前端常仍是 JupyterLab；部署与认证见 JupyterHub 入门。

七、小结

项 说明
安装 python -m pip install jupyterlab
启动 jupyter lab，使用终端中的 token URL
安全 优先 127.0.0.1；远程用 SSH 转发 或 Hub + HTTPS
延伸 Jupyter · JupyterHub

界面与快捷键随 JupyterLab 大版本迭代会有差异，以你安装的版本对应文档为准。
