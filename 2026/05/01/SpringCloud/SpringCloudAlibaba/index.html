Spring Cloud Alibaba 与 Gradle 从零搭建

发表于 2026-05-01 更新于 2026-05-04 分类于 SpringCloud 本文字数： 1.9k 阅读时长 ≈ 6 分钟

Spring Cloud Alibaba（简称 SCA）在 Spring Cloud 之上整合 Nacos、Sentinel、Seata、RocketMQ 等组件，便于做注册发现、配置、限流与分布式事务。本文先说明 版本怎么选，再用 IntelliJ IDEA 创建 Gradle（Kotlin DSL） 工程，按后文替换构建脚本与依赖，得到可启动、可连 Nacos 做服务注册的最小示例；构建工具安装与镜像加速见站内 gradle.md。

一、官网与文档

  • 中文官网：https://sca.aliyun.com/
  • GitHub：https://github.com/alibaba/spring-cloud-alibaba
  • 版本说明（与 Spring Boot / Spring Cloud 对齐关系）：https://sca.aliyun.com/docs/2025.x/overview/version-explain/
  • 发行说明与变更：https://github.com/alibaba/spring-cloud-alibaba/releases

二、版本选型（先做这一步）

SCA 以 BOM 三位版本号（如 2025.1.0.0）发布，须与 Spring Boot、Spring Cloud 同一世代，不能混用旧版 Boot 配新版 SCA。

1. 当前两条主线（摘自官方 README 分支说明）

路线 Spring Boot Spring Cloud SCA BOM（示例） JDK 适用场景
2025.1.x（本文采用） 4.0.x 2025.1.x 2025.1.0.0（当前 GA） 17+ 新项目、跟官方最新发布版
2025.0.x 3.5.x 2025.0.x 2025.0.0.x（以 Central 为准） 17+ 暂不升级 Boot 4、存量 Boot 3.5

2. 本文固定组合（与 SCA 2025.1.0.0 发行说明一致）

  • Spring Cloud Alibaba BOM：2025.1.0.0（com.alibaba.cloud:spring-cloud-alibaba-dependencies）
  • Spring Boot：4.0.4（4.0 线补丁，仍属官方所述 Boot 4.0.x）
  • Spring Cloud BOM：2025.1.0（org.springframework.cloud:spring-cloud-dependencies）
  • JDK：17（官方要求 17+，可用 21）
  • Gradle：与 gradle.md 一致，示例 Wrapper 使用 9.5.0

2025.1.x 起 Nacos 配置侧已弱化 bootstrap.yml，推荐 spring.config.import 或直接在 application.yaml 中配置；本文最小示例只用 application.yaml + Nacos 注册发现。

升级小版本前请到 GitHub Releases 与 sca.aliyun.com 核对是否仍有更新的 2025.1.0.x 补丁版，并替换下文的 BOM 与 Boot 小版本号。

三、环境与前置

  1. 安装 JDK 17+，终端执行 java -version。
  2. 安装 IntelliJ IDEA（Community / Ultimate 均可；下文以 Ultimate 菜单名为准，社区版对应项名称可能略有差异）。
  3. 安装 Gradle（或使用下文 gradle wrapper 生成 Wrapper，本机需已装 Gradle 一次），参见 source/_posts/Java/gradle.md；亦可在 IDEA 内用自带 Gradle 执行同步与 bootRun。
  4. 若要验证注册发现：本机或服务器已部署 Nacos 2.x / 3.x（示例地址 127.0.0.1:8848）。无 Nacos 时工程仍可 编译；启动后若连不上注册中心，控制台会有连接相关日志。

四、用 IntelliJ IDEA 创建工程（替换原手动建目录）

不要使用 Spring Initializr 向导直接生成完整 Boot 工程：本文 build.gradle.kts 需手写 Spring Cloud / SCA BOM，与 Initializr 默认模板不一致。请用 IDEA「Java + Gradle」向导 建骨架，Gradle DSL 必须选 Kotlin（与 「五～七」 文件名一致），再按 「五～七」 覆盖脚本。

1. 新建项目：左侧「Java」+ 构建系统「Gradle」

与 IntelliJ IDEA 新版「新建项目」界面一致（欢迎页 New Project / 菜单 File → New → Project）：

  1. 左侧在 New Project 下选 Java；右侧 Build system（构建系统） 选 Gradle（与 IDEA 当前「Java + Gradle」向导一致）。若你习惯用左侧 Gradle 向导，同样必须把 Gradle DSL 设为 Kotlin，效果等价。
  2. 右侧 Name（名称）：填 sca-nacos-demo（与下文工程名一致）。
  3. Location（位置）：选父目录，IDEA 会在其下创建 sca-nacos-demo 文件夹。
  4. Create Git repository（创建 Git 仓库）：按需勾选（团队协同时建议勾选）。
  5. Build system（构建系统）：选 Gradle。
  6. JDK：选 17 或 21（须满足「二」中 17+；与 build.gradle.kts 里 JavaLanguageVersion.of(17) toolchain 一致时，选 17 最省事）。
  7. Gradle DSL：务必选 Kotlin（生成 build.gradle.kts / settings.gradle.kts）。向导默认有时是 Groovy（生成 build.gradle），与本文不符。若已误选 Groovy：最省事是重新 New Project 并改选 Kotlin；或手动新建 build.gradle.kts、settings.gradle.kts，删除 build.gradle、settings.gradle 后 Reload Gradle Project。
  8. Add sample code（添加示例代码）：建议取消勾选，减少默认 Main.java；若保留，完成 「九」 前删除向导生成的示例类即可。
  9. 点击 Create（创建）。IDEA 会生成 src/main/java、src/main/resources、gradle/ 等，无需再手动 mkdir。

2. 创建 Java 包与源码目录

  1. 在 Project 视图中展开 src/main/java。
  2. 在 java 上右键 → New → Package，输入 com.example.sca 并确认。
  3. 后续 「九」 中的 ScaDemoApplication.java、HelloController.java 均建在该包下；application.yaml 放在 src/main/resources/。

向导生成的 settings.gradle.kts、build.gradle.kts 往往带演示性 main 函数或默认依赖，请打开文件后整段替换为 「五」「七」 中的内容；新建 gradle.properties 并写入 「六」。保存后点击右上角 Load Gradle Changes（或 Gradle 工具窗口的刷新），等待依赖解析完成。

十一、小结

项 说明
SCA BOM 2025.1.0.0（发布版；升级请看 GitHub Releases）
Spring Boot / Cloud 4.0.4 + 2025.1.0，与 2025.1.x 主线一致
创建方式 IntelliJ IDEA：Gradle + Kotlin DSL 向导，再覆盖 「五～七」 脚本
构建 Gradle Kotlin DSL，Wrapper 9.5.0
注册发现 spring-cloud-starter-alibaba-nacos-discovery + application.yaml
官方文档 https://sca.aliyun.com/ · https://github.com/alibaba/spring-cloud-alibaba

按上述顺序即可用 IDEA 得到可维护的最小 Spring Cloud Alibaba + Gradle 工程；需要 Sentinel / Seata / RocketMQ 时在 build.gradle.kts 增加对应 spring-cloud-starter-alibaba-* 依赖，并查阅官网各组件章节继续配置即可。
