Spring Cloud Alibaba 接入 Sentinel（SCA 2025.1.x 与控制台）

发表于 2026-05-01 更新于 2026-05-02 分类于 SpringCloud 本文字数： 715 阅读时长 ≈ 2 分钟

Sentinel 提供流量控制、熔断降级、系统自适应保护等能力；在 Spring Cloud Alibaba 中通过 spring-cloud-starter-alibaba-sentinel 开箱接入 Web 与常见远程调用场景。SCA 2025.1.0.0 将 Sentinel 核心库对齐到 1.8.9，并与 Spring Boot 4.x / Jackson 3.x 兼容（见 Release 说明）。BOM 与 Gradle 工程见 Spring Cloud Alibaba 与 Gradle 从零搭建。

与 Spring Cloud Alibaba 的版本关系

项 建议 说明
SCA BOM 2025.1.0.0 以 GitHub Releases 为准
Sentinel Core（BOM） 1.8.9 spring-cloud-alibaba-dependencies 中 sentinel.version
Sentinel Dashboard 与 1.8.x 控制台匹配 建议从 Sentinel Releases 下载 sentinel-dashboard-1.8.9.jar（或与 1.8.9 同线的控制台包）

官方文档

  • SCA 2025.x Sentinel 快速开始：https://sca.aliyun.com/docs/2025.x/user-guide/sentinel/quick-start/
  • Sentinel 文档（规则、注解）：https://sentinelguard.io/zh-cn/docs/introduction.html

依赖（Gradle Kotlin DSL）

引入后，Spring MVC 暴露的 HTTP 接口默认会作为资源被统计（是否限流仍由规则决定）；可与 OpenFeign、RestTemplate 等扩展一起使用（按需加 spring-cloud-starter-openfeign 等）。

连接 Sentinel Dashboard

Dashboard 独立进程运行；应用通过 transport 与控制台通信。

application.yaml 示例：

  • dashboard：控制台 IP:端口（勿与业务 HTTP 端口冲突；示例控制台常用 8858）。
  • port：应用侧与 Dashboard 通信的本地端口，未占用时可保持默认 8719。

启动控制台（示例将控制台 HTTP 设为 8858）：

浏览器访问 http://127.0.0.1:8858（默认账号密码以 Dashboard 发行说明为准，首次登录后应修改）。

若 Dashboard 挂在 context-path 下，需配置 spring.cloud.sentinel.transport.api-path 等项，见 SCA 高级文档与 Issue 讨论。

标识资源：@SentinelResource

对需要单独配置流控、熔断的方法使用 @SentinelResource，例如：

blockHandler / fallback / blockHandlerClass 等用法见 Sentinel 注解支持。

Feign 与 RestTemplate（可选）

  • Feign：在启用 Feign 的前提下，配置 feign.sentinel.enabled=true（Spring Cloud 2025.x 下属性名以当前 SCA 文档为准），使远程调用资源纳入 Sentinel。
  • RestTemplate：按 SCA 文档添加 @SentinelRestTemplate 或推荐的全局 RestTemplate 封装方式。

具体包名与自动配置类随 Boot 4 可能有细微差异，以 spring-cloud-starter-alibaba-sentinel 当前版本说明为准。

规则持久化（简述）

默认规则存内存；生产可将流控、降级等规则放到 Nacos、Redis 等数据源，使用 sentinel-datasource-* 与 SCA 文档中的 spring.cloud.sentinel.datasource 配置。与 Nacos 同栈时，可统一由 Nacos 推送规则。

参考链接

  • SCA 版本说明：https://sca.aliyun.com/docs/2025.x/overview/version-explain/
  • Sentinel GitHub：https://github.com/alibaba/Sentinel
  • SCA 2025.1.0.0 Release：https://github.com/alibaba/spring-cloud-alibaba/releases/tag/2025.1.0.0

固定 SCA BOM 2025.1.0.0 后，增加 spring-cloud-starter-alibaba-sentinel、配置 transport.dashboard 并启动 1.8.9 控制台，即可在界面上配置 QPS、线程数、熔断等规则，与 Seata、RocketMQ 等组件可并存使用。
