OpenSSL 证书与密钥 完整指南

OpenSSL 是生成、管理非对称密钥和数字证书的标准工具，广泛用于 HTTPS、SSL/TLS、身份认证、加密通信等场景。

一、核心概念（快速看懂）

  1. 私钥（private key）：.key / .pem，必须保密，用于解密、签名
  2. 公钥（public key）：从私钥导出，公开分发，用于加密、验签
  3. 证书（certificate）：.crt / .pem，包含公钥 + 身份信息 + 签名，证明公钥合法
  4. CSR（证书签名请求）：.csr，向 CA 机构申请正式证书的文件

二、最常用命令（直接用）

1. 生成 RSA 私钥（无密码）

  • 2048 是密钥长度（安全推荐）
  • 生成后千万不要泄露

2. 生成带密码保护的私钥（更安全）

每次使用会要求输入密码。

3. 从私钥导出公钥

三、生成自签名证书（开发/测试必备）

自签名证书 = 私钥 + 自己签发的证书
适合本地开发、内网测试，不能用于公网生产环境。

一步生成 私钥 + 证书（有效期 10 年）

  • -nodes：私钥不加密
  • -days 3650：有效期 10 年
  • 执行后按提示填信息（可以全部回车）

最终得到两个文件：

  • private.key：私钥
  • cert.crt：自签名证书

四、生成 CSR（向 CA 申请正式证书）

如果你要申请阿里云/腾讯云/Let’s Encrypt 正规证书，必须先生成 CSR。

1. 生成私钥

2. 生成 CSR 请求文件

提交 cert.csr 给 CA 机构，就能拿到正式证书。

五、证书/密钥查看命令

1. 查看私钥信息

2. 查看证书信息（最常用）

3. 查看 CSR 信息

4. 验证 私钥 和 证书 是否匹配

两个 MD5 值完全相同 = 匹配

六、格式转换（最常见需求）

1. PEM 转 PKCS#12（.pfx / .p12，Windows/IIS 用）

2. 从 PFX 提取 私钥 + 证书

3. DER 转 PEM

七、生产环境标准流程

  1. 生成安全私钥（4096 位，带密码）
  2. 生成 CSR
  3. 提交 CSR 给 CA → 获取正式证书
  4. 部署证书（Nginx/Apache/IIS）

总结

  1. 开发用：自签名证书（私钥 + crt）
  2. 生产用：CSR 申请正规证书
  3. 必备命令：生成密钥、查看证书、格式转换、验证匹配
  4. 私钥绝对不能泄露，泄露等于证书失效
