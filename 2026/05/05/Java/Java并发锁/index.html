涵盖：synchronized、ReentrantLock、ReentrantReadWriteLock、StampedLock、Atomic原子类、volatile

一、synchronized 内置锁

特性

可重入、非公平、悲观独占锁，JVM 自动加解锁。

适用场景

简单临界区、单体小并发、不想手动释放锁。

二、ReentrantLock 可重入显式锁

特性

可重入、支持公平/非公平、可超时、可中断、多 Condition 精准唤醒。

适用场景

需要锁超时、可中断、公平锁、复杂生产者消费者。

基础使用示例

tryLock 超时避免死锁

三、ReentrantReadWriteLock 读写锁

特性

读读共享、读写互斥、写写互斥。

适用场景

读多写少：本地缓存、配置类、字典数据。

代码示例

四、StampedLock 乐观读写锁（JDK8+）

特性

支持乐观读、悲观读、写锁，无锁乐观读性能极高。

适用场景

超高并发、读极多写极少，追求极致性能。

代码示例

五、Atomic 原子类（无锁 CAS）

特性

基于 CAS 无锁，原子性、高性能，不阻塞。

适用场景

计数器、序号生成、简单状态标记，单个变量原子操作。

代码示例

六、volatile 轻量级可见性（非锁）

特性

保证可见性、禁止指令重排，不保证原子性。

适用场景

状态标志位、双重校验单例。

代码示例

七、锁选型速查表

锁类型 核心特点 适用场景
synchronized 简单自动加解锁、可重入 简单临界区、低并发、快速开发
ReentrantLock 公平/非公平、超时、中断、Condition 复杂同步、需要超时/可中断、生产者消费者
ReentrantReadWriteLock 读读共享、读写互斥 读多写少：本地缓存、配置字典
StampedLock 乐观读、高性能 超高并发、读极多写极少
AtomicXXX CAS无锁、高性能 计数器、自增序号、单个变量原子操作
volatile 可见性+禁止重排 状态标记、双重检查单例
