SpringBoot多环境协同

发表于 2026-05-08 分类于 SpringBoot 本文字数： 465 阅读时长 ≈ 2 分钟

Profile + application-share.yml（公共配置） + 多环境配置（dev/test/prod）并存方案

示例

最终效果：

  1. 项目启动先加载 application-share.yml（公共）
  2. 再加载 当前环境配置（dev/test/prod）
  3. 环境配置 > 共享配置（相同key覆盖）
  4. Nacos / 本地文件 都支持这种结构

二、SpringBoot 激活多环境方式

1. application.yml 主配置

✅ 作用：

  • active: dev：激活 application-dev.yml
  • include: share：额外加载共享配置 application-share.yml

这就是你要的 共享文件 + 环境文件并存

三、文件结构（标准规范）

四、加载优先级（从低 → 高）

  1. application.yml（最低）
  2. application-share.yml（公共）
  3. application-dev.yml（当前环境，最高）

相同配置项：环境配置会覆盖共享配置！
非常适合：

  • 公共：端口、前缀、MyBatis、框架配置
  • 环境：数据库、Redis、Nacos地址

五、如果是 Nacos 配置中心（你一定会用到）

1. 共享配置：share.yaml

2. 环境配置：service-demo-dev.yaml

3. bootstrap.yml 加载共享 + 环境配置

✅ Nacos 会自动加载：

  1. share.yaml（公共）
  2. service-demo-dev.yaml（环境）

六、最核心一句话（必背）

这一行就是让 共享配置 share.yml 和 当前环境配置 dev/test/prod.yml 同时生效的关键。
